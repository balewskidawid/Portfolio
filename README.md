# Engineering Portfolio

This repository contains a collection of my engineering and programming projects developed during my studies and personal technical work. The projects cover object-oriented programming in C++, microcontroller-based systems, PLC control, robot simulation, mechanical design, and renewable energy applications.

The purpose of this portfolio is to present practical engineering skills through complete project examples, including software implementation, system design, automation concepts, hardware-software integration, and technical problem solving.

## About

I am an engineering student interested in automation, robotics, embedded systems, and practical software development. My projects combine programming, control systems, mechanical design, and real engineering applications.

## Project Areas

### Object-oriented C++

Projects focused on application logic, object-oriented programming, and structured code design. They include simulations and interactive programs created to practice classes, objects, encapsulation, modularity, and complete program architecture.

### Microprocessor Systems

Arduino-based projects involving sensors, actuators, control logic, and basic embedded systems. These projects demonstrate practical experience with hardware-software integration and simple automation tasks.

### Robot Simulation

Simulation-based robotics projects focused on modeling, control, and analysis of robotic systems in a virtual environment.

### Mechanical Designs

Mechanical engineering projects and CAD-based designs presenting practical design skills, technical documentation, and engineering problem solving.

### Solar Tracking PV Installation

A dual-axis photovoltaic tracking system created as a family engineering project. The system uses PLC-based control to adjust panel position according to a time-based sun-tracking algorithm and improve energy yield compared to a fixed installation.
